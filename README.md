# AI NoteBot

An AI-powered RAG chatbot that allows users to upload PDFs and ask questions from their notes using semantic search and LLM-based responses.

## Features
- PDF upload and processing
- Semantic similarity search
- FAISS vector database
- Groq LLM integration
- HuggingFace embeddings
- Chat memory
- Streamlit UI

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- HuggingFace
- Groq API

## Run Locally

pip install -r requirements.txt

streamlit run app.py
